Project Overview

A simulated and simplified flight control system that demonstrates priority inversion and the importance of proper mutex implementation in an aerospace embedded system.

The Scenario

A small drone, deployed from a nearby spacecraft currently orbiting Mars, must periodically adjust its attitude and trajectory, map the Martian surface, and upload telemetry to its host spacecraft.

Three FreeRTOS tasks cooperate to perform these functions while sharing a common navigation resource. This project demonstrates how improper synchronization can significantly increase the response time of a high-priority real-time task through priority inversion.

Project Objectives

  • Demonstrate the classic priority inversion problem using FreeRTOS.
  • Compare mutexes with priority inheritance against binary semaphores.
  • Measure task WCET and response time under both synchronization methods.
  • Analyze the impact of resource sharing on schedulability.

Priority Inversion Scenario

The Telemetry Logger periodically acquires a shared navigation resource in order to upload flight data to the host spacecraft. The Flight Control task also requires this resource during each control cycle.

A third task, Terrain Mapping, performs computationally intensive image and lidar processing but never accesses the shared resource. If priority inheritance is disabled, this medium-priority task can repeatedly preempt the Telemetry Logger while the Flight Control task waits, producing the classic priority inversion problem.

Priority Inheritance

When a FreeRTOS mutex is used, the Telemetry Logger temporarily inherits the Flight Control task's priority while it owns the shared resource. This prevents the Terrain Mapping task from extending the blocking time and bounds the response time of the Flight Control task.

Replacing the mutex with a binary semaphore removes this ownership mechanism, allowing unbounded priority inversion to occur. 

USE_PI_MUTEX = 1    // FreeRTOS mutex (priority inheritance)

USE_PI_MUTEX = 0    // Binary semaphore (no priority inheritance)
